# Ansible

Run Ansible automation from your repositories. Register a playbook, give it an inventory that stays current with your cloud or repository, then launch jobs from a template. Jobs run on hosted capacity or on an agent pool's [launchers](../launchers/README.md).

New to Ansible on Stackweaver? Start with [your first Ansible job](../../get-started/your-first-ansible-job.md).
