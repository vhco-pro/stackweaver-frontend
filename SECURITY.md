# Stackweaver security policy

To report a suspected vulnerability in Stackweaver, its release artifacts, or
its release pipeline, [open a private vulnerability report](https://github.com/vhco-pro/stackweaver-frontend/security/advisories/new).
If you cannot use GitHub, send a short summary to
[contact@vhco.pro](mailto:contact@vhco.pro) and ask for a secure way to share
sensitive follow-up. Include the affected component and release if known.
Keep vulnerability details out of public issues.

We'll coordinate disclosure with you. Security fixes go into the latest
Stackweaver release. See [Verify a Stackweaver release](https://stackweaver.sh/docs/security/verifying-releases)
for signature and provenance checks.
